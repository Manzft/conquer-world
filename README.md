# Conquer World

Un prototipo de juego de estrategia inspirado en clásicos como **Victoria 2** y **Europa Universalis 4**.

## Sobre el Proyecto

Conquer World es un prototipo en desarrollo que busca replicar la experiencia de gestión y conquista territorial de los juegos de estrategia histórica. Actualmente incluye:

- **Mapa procedural**: Sistema de tiles que genera un mundo jugable
- **Ciudades**: Entidades clickeables con conexiones entre ellas
- **Sistema de navegación**: Pathfinding con A* para rutas entre ciudades
- **Cámara**: Movimiento con WASD/flechas, drag con botón del medio y zoom con rueda del ratón

## Controles

| Acción | Tecla/Ratón |
|--------|-------------|
| Mover cámara | WASD / Flechas |
| Arrastrar cámara | Botón del medio + movimiento |
| Zoom | Rueda del ratón |
| Seleccionar ciudad | Click izquierdo |

## Tecnologías

- **Motor**: Godot 4.6
- **Lenguaje**: GDScript
- **Renderizado**: GL Compatibility

## Cómo Ejecutar

1. Clonar el repositorio
2. Abrir el proyecto en Godot 4.6
3. Ejecutar la escena principal

## Estado actual
